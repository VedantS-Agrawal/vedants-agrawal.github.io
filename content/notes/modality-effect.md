How the mode of presenting material affects memory and learning.

For serial recall, auditory beats visual (4.8 vs 5.36 words).

This relationship is interesting. Words are first taken in as visual images and then translated into their language components, so it would follow that presenting language-based material by ear is more efficient. There might also be something in how information enters working memory — whether running two modalities at once uses cognitive resources more efficiently.
