The amount of information flowing into working memory at any moment. Working memory is the brain's scratchpad: we're only aware of what's in it, and to think about something we've learned, it has to come back up from long-term memory.

Three kinds, all drawing on the same limited reservoir:

- **Intrinsic** — effort that belongs to the topic itself.
- **Extraneous** — effort caused by how the material or task is presented.
- **Germane** — the work of building a permanent store of knowledge, a schema.

Extraneous load takes room away from intrinsic load. And when working memory is full, germane load — the actual learning — doesn't happen as readily. The schemas we build come out shallower.

The two biggest sources of overload, per [The Shallows](/library/the-shallows-what-the-internet-is-doing-to-our-brains): problem-solving and divided attention. Which bodes poorly for the web, where the brain regions for both are highly active.
